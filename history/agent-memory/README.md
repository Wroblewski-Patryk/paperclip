# Agent Memory Archive

This directory preserves lossless historical snapshots rotated out of active
agent memory.

Rules:

- Do not load this directory by default.
- Search it only for historical reconstruction, provenance, or recovery of a
  detail not present in current truth.
- Archived statements may be stale, duplicated, or superseded.
- Current product contracts, active state, decisions, and freshly verified
  evidence always take precedence.
- Never rewrite an archived snapshot merely to make old claims look current.
  Record corrections in the active decision/current-truth layer instead.
