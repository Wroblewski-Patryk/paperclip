# Process Improvement

Paperclip Softwarehouse uses PDCA: Plan, Do, Check, Act.

## Improvement Triggers

Create or update an improvement issue when:

- the same test/deploy/security failure repeats;
- an agent run exits without a useful final report or next action;
- a task is blocked by a missing secret, tool, repo permission, or unclear owner;
- documentation fails to tell the next agent what to do;
- production and local state disagree;
- a supervisor holds too much broad work without worker-ready decomposition.

## Improvement Output

An improvement task must produce at least one of:

- updated policy or AGENTS guidance;
- fixed script/automation;
- dashboard or audit signal;
- new test or smoke check;
- clarified agent role/capability;
- evidence-map update.
