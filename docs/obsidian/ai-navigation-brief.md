## Before Editing

- Identify the affected user path or function chain.
- Identify source files, tests, docs, and proof gaps.
- Preserve current-vs-history boundaries.
- Keep claims conservative when production or external systems are involved.

## After Editing

- Run the smallest meaningful verification.
- Update canonical docs and graph files if ownership, routes, functions, APIs, or proof changed.
- Regenerate the Obsidian layer.
