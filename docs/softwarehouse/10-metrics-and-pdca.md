# Metrics And PDCA

Status: active baseline
Date: 2026-06-03
Owner: Portfolio Director

Metrics exist to improve autonomy, not to decorate reports.

## PDCA Contract

Every meaningful task follows:

- PLAN: goal, context, acceptance, risk, owner, process class
- DO: smallest logical work increment
- CHECK: verification against acceptance
- ACT: docs, follow-up, process update, handoff, or closure

## Minimum Metrics

- lead time from intake to DONE
- number of stale `in_progress` issues
- number of blocked issues without unblock owner
- done-without-proof count
- repeated blocker themes
- deployment frequency
- change failure rate
- mean time to recovery
- docs drift count
- current-truth drift count
- archived evidence reused as current truth count
- security gate failures

## Continuous Improvement Rule

When the same class of blocker repeats, create one of:

- process update
- checklist update
- role boundary update
- automation/audit issue
- capability gap note
- knowledge promotion, supersession, or archive update

Do not solve repeated process failure by telling agents to "try harder".
