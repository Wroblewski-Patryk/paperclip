# Supervisor Agents

Supervisor agents keep autonomous execution constructive. Their job is to close loops, not to add
ceremony.

## Supervisor Responsibilities

- inspect active and stalled work;
- decompose broad supervisor-held issues into worker-ready tasks;
- verify evidence bundles before completion;
- route failed tests, deploys, and monitoring checks back to the correct owner;
- create process-improvement tasks when failure patterns repeat;
- maintain role boundaries and autonomy levels;
- ensure branch/worktree discipline.

## SupervisorReview

Until a dedicated normalized table is added, a supervisor review is represented by issue approvals,
issue thread interactions, supervisor-owned review issues, comments, work products, and activity log
entries.

The review must state:

- decision: approved, changes requested, blocked, or escalated;
- evidence checked;
- risks remaining;
- next owner and next action.
