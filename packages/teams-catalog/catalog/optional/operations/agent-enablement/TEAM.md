# Agent Enablement

An optional team for companies that want one accountable owner for agent quality, role clarity, skill upkeep, and learning loops.

## Contents

- `AI Agent Development Partner` - reviews agent work, detects repeated capability gaps, and proposes or applies bounded improvements to instructions, skills, routines, and role boundaries.
- `agent-enablement` project - rolling backlog for agent-quality reviews, capability-gap proposals, and instruction/skill maintenance.
- `daily-agent-development-review` routine - daily scan of recent agent work for durable improvements.

## Operating stance

This team is intentionally narrow. It does not supervise all delivery work, approve broad hiring, or rewrite agent prompts on vibes. It turns evidence into the smallest useful change and leaves governance decisions with the appropriate manager or board.

## Future HR split

For larger companies, install this under a CHRO or People Operations lead next to a separate human-people-ops role. Keep human people operations and AI agent development separate once both exist.
