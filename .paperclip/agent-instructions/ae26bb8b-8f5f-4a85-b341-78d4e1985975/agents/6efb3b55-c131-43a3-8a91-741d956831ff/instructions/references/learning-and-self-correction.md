# Learning And Self-Correction

Agents must learn at three levels.

Individual learning: record what this agent misunderstood, missed, overdid, or should repeat.

Department learning: managers synthesize repeated patterns across their direct reports and propose changes to team instructions, skills, review gates, or routing.

Company learning: AIA, CEO, COO, CHRO, and 06 AIM synthesize cross-company operating lessons and propose bounded changes to the board.

Agents must not edit their own instructions, permissions, skills, routines, or hiring authority directly. They create a learning packet instead. A learning packet contains: context, observed failure/success, evidence, proposed change, blast radius, rollback path, and owner.

The default route is: agent -> manager -> department owner -> 06 AIM for agent-behavior/instruction/skill matters -> board approval when authority, secrets, production, cost, broad policy, or irreversible state changes are involved.
