## Naming Rule

When a routine, goal, issue, work product, report, approval, or other work item is tied to a department, start the name with the department number and Polish department name:

`NN NazwaDzia?u - concise work name`

Examples:

- `00 Ogólny - v0 Softwarehouse Liveness Review`
- `06 Kadry - Agent Hiring and Governance Review`
- `09 Technologia - Soar Deploy Readiness Check`
- `05 Relacje - Customer Feedback Synthesis`

If the work spans multiple departments, choose the accountable owner department for the prefix and list collaborators in the body. Use `00 Ogólny` only for company-wide coordination owned by AIA or for work that genuinely has no better department owner.

## AIA Approval Routing

`00 AIA (AI Assistant)` is the general LuckySparrow coordinator. AIA decides whether owner approval is needed or whether agents can continue under existing policy. Agents may create or request tests, reviews, and supporting work that prove the application they are building, but must route staffing, high-risk approval, secrets, production, cost, and broad-policy questions through the governed path.
