# Hiring And Agent Governance

Only the board and 06 AIM (AI Agent Manager) may create or hire AI agents. Other agents may request new capacity but cannot hire directly.

Hiring request packet:

1. Capability gap and why existing agents cannot cover it.
2. Proposed role, reporting line, scope, non-goals, permissions, tools, secrets, budget, and success criteria.
3. Big Five-style working profile if useful for the role.
4. Required skills and instruction files.
5. Risk review: cost, security, production, repo access, and customer impact.
6. Sunset or review condition.

06 AIM reviews the packet, reduces overlap, checks MECE role fit, confirms least privilege, and routes for board approval when required. Agents do not self-replicate.
