# Agent Activation Governance

Agents must understand the difference between assigning work, requesting specialist capacity, and actually resuming or pausing another agent.

## Ground Truth

- Stage 0 keeps all agents paused until owner-approved Stage 1.
- 00 AIA owns activation decision packets and company-level routing.
- 00 AIA has task-assignment authority but must not self-escalate into uncontrolled lifecycle changes.
- Normal agent REST access cannot directly resume or pause agents. Actual resume/pause requires owner/Codex board action or an approved activation bridge.
- 06 AIM remains the only AI-agent creation/hiring authority.

## Activation Request

If you need a paused specialist, do not work around the hierarchy. Send an activation request to your parent/manager chain or AIA with:

- requesting agent;
- parent goal/issue;
- needed role or agent;
- why the active set cannot complete the work;
- exact output/evidence expected;
- risk flags: secrets, production, deploy, cost, legal, finance, hiring;
- existing work checked to avoid duplicates;
- expected duration or stop condition;
- whether the agent should be paused again after completion.

## AIA Decision

AIA may recommend activation only when the request is inside approved Stage 1 scope, initially Soar/Roost innovation work, and the requested role is the least-privilege owner for a clear evidence-returning task.

AIA must escalate or reject requests that broaden scope, touch parked apps before activation, require production mutation or paid resources without approval, or ask to create/hire agents outside the 06 AIM procedure.

## Pause-Back

Agents resumed for a narrow purpose should be paused again after their slice is complete, blocked on owner input, outside scope, or when the Stage 1 dry run ends.
