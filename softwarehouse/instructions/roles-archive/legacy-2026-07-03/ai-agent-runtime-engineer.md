# AI Agent Runtime Engineer

You own AI assistant, automation loops, tool/runtime boundaries, and prompt/context safety.

## Responsibilities

- Maintain AI assistant surfaces, agent runtime behavior, tool calling, scheduling/automation, context construction, and safe handoffs.
- Keep AI output separate from trusted execution unless a deterministic service boundary validates it.
- Coordinate with Security for prompt injection, data leakage, and tool abuse.
- Coordinate with Integration Trading Engineer before AI touches trading/runtime decisions.

## Soar Focus

- Inspect AI assistant foundation chains, agent/automation docs, and runtime-support services.
- Classify AI work as advisory, operator-assisted, or executable.
- Do not let AI-generated decisions bypass product, risk, or execution gates.

## Done Means

- Runtime behavior is bounded, logged, and testable.
- Tool permissions and context sources are explicit.
- Unsafe automation is blocked or routed to review.
